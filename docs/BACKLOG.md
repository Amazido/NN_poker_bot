## Дорожка

### Этап 1 — каркас конфигурации правил

Цель: сделать редакцию правил настоящей точкой расширения и выпустить на ней
первые варианты игры.

- Схема конфига с `schema_version` и блоками по смыслу (`deck`, `rounds`,
  `ranking`, `bidding`, `scoring`).
- **Валидация редакции** при создании редакции и стола. Сейчас её нет вообще:
  несовместимый конфиг падает в рантайме посреди раздачи.
- Заменить **тихое урезание** раздачи под размер колоды на явную ошибку.
  Сейчас «13 карт на пятерых» молча превращается в 10.
- Колода читается из конфига (`build_deck`, `DECK_SIZE` сейчас захардкожены).
- Вывести наружу уже работающие в движке `ranking` и `scoring`.
- `GET /rules/editions` — список доступных редакций с человекочитаемым описанием.
- Фронт: выбор редакции при создании стола, плашка «правила стола» на столе.
  Сейчас игрок вообще не знает, по каким правилам сел играть.
- Сид нескольких редакций помимо классики.

Выпускаемые правила этапа: старшинство (`two_beats_ace_same_suit`,
`offcolor_beats_oncolor`), настраиваемые награды, лимиты раздачи.

### Этап 2 — колода и заказ вслепую

- `deck.infinite` — бесконечная колода, карты тянутся случайно из 54 типов
  и могут повторяться в одной руке и у разных игроков.
- `ranking.duplicate_first_wins` — кто берёт взятку при одинаковых картах.
- `bidding.blind_allowed` — заказ, не открывая руку, и `scoring.blind_bonus`.

Заказ вслепую нужен до сезона: он входит в эталонную редакцию сезона 1.

### Этап 3 — сезоны, рейтинг, награды

Отдельный большой заход. Понятие сезона, эталонная редакция сезона, общий
лидерборд, система рейтинга, награды. Требует отдельного разговора по визуалу —
экранов здесь больше, чем во всей остальной игре.

Не начинаем, пока не закрыты этапы 1 и 2.

## Отложено

### Одновременные заказы (`bidding.simultaneous`)

Все заказывают в одно общее окно, не видя чужих заказов. Ортогонально заказу
вслепую: включаются независимо и сочетаются (тогда игрок не видит ни своей
руки, ни чужих ставок).

Отложено, потому что сезон 1 играется последовательным заказом.

Почему это дорого: сейчас торги — строгая очередь (`bid_turn` идёт по кругу).
Одновременный режим меняет машину состояний раздачи, публичный вид (заказы
нельзя показывать до вскрытия), таймер хода (общий дедлайн вместо
персонального) и экран торгов на фронте.

**Решение принято заранее:** при `simultaneous` крюк отключается. Последнего
заказывающего не существует, цеплять правило не к чему.

## Пространство правил (цель)

Таблицы описывают **целевой** конфиг, а не текущий. Реализованное по мере
выпуска переезжает в `ARCHITECTURE.md`.

### Переключатели

| Опция | Что делает | Состояние |
|---|---|---|
| `ranking.two_beats_ace_same_suit` | двойка бьёт туза своей масти, если оба в одном сбросе | в движке есть, наружу не выведено |
| `ranking.offcolor_beats_oncolor` | некозырной джокер бьёт козырного | в движке есть, наружу не выведено |
| `ranking.duplicate_first_wins` | при одинаковых картах взятку берёт положивший раньше | не сделано |
| `deck.infinite` | бесконечная колода, карты повторяются | не сделано |
| `bidding.hook` | сдающий не может сделать сумму заказов равной числу карт | зашито жёстко, вынести в конфиг |
| `bidding.blind_allowed` | можно заказать, не открывая руку | не сделано |
| `bidding.simultaneous` | все заказывают в одно окно, не видя чужих | отложено |

### Числовые параметры

| Параметр | Классика | Сезон 1 |
|---|---|---|
| `rounds.peak` | 10 | 10 |
| `rounds.max_cards` | по колоде | по колоде |
| `players.min` / `players.max` | 3 / 5 | 3 / 5 |
| `scoring.exact_per_trick` | 10 | 10 |
| `scoring.exact_zero_bonus` | 10 | 10 |
| `scoring.over` | −5 | −5 |
| `scoring.under_per_trick` | −10 | **−5** |
| `scoring.blind_bonus` | — | 5 |
| `turn_timeout_sec` | 30 | 30 |

### Связанные и несовместимые сочетания

Семь переключателей дают 128 комбинаций на бумаге, но часть из них лишена
смысла. Осмысленных — 72.

- `ranking.duplicate_first_wins` работает только при `deck.infinite`. В обычной
  колоде двух одинаковых карт не бывает, флаг ни на что не влияет.
- `bidding.hook` несовместим с `bidding.simultaneous` — отключается
  принудительно (см. «Отложено»).

Гонять все 72 сочетания смысла нет. Проверяем каждый переключатель отдельно
против базовой редакции плюс пересечения, где правила трутся друг о друга:

- **`deck.infinite` + два одинаковых джокера в одной взятке.** Самое
  опасное место. `cards.trick_winner` выбирает джокера нужного цвета через
  `next()`, то есть первого в порядке хода. Это случайно совпадает с
  «берёт положивший раньше», но совпадение надо закрепить тестом, иначе
  любая правка функции тихо изменит правило.
- **`deck.infinite` + `two_beats_ace_same_suit`.** `_effective_rank` ищет туза
  той же масти среди сыгранных карт. При повторах в одной взятке может
  оказаться несколько двоек и несколько тузов одной масти.
- **`deck.infinite` + одинаковые козыри в одной взятке.**
- **`blind_allowed` + `hook` у сдающего.** Сдающий обязан не добить сумму
  заказов до числа карт, не видя своей руки. Правило работает, играть тяжело —
  похоже, ровно ради этого вслепую и вводится.

### Эталонная редакция сезона 1

```json
{
  "deck":    { "infinite": false },
  "ranking": { "two_beats_ace_same_suit": true,
               "offcolor_beats_oncolor": true },
  "bidding": { "simultaneous": false, "hook": true, "blind_allowed": true },
  "scoring": { "exact_per_trick": 10, "exact_zero_bonus": 10,
               "over": -5, "under_per_trick": -5, "blind_bonus": 5 }
}
```

Отличия от классики: двойка бьёт туза, некозырной джокер бьёт козырного,
недобор подешевел с −10 до −5 за взятку, появился заказ вслепую.

## Принятые решения

Чтобы не переобсуждать. Решения по уже выпущенному переезжают в `CHANGELOG.md`.

**Безлимитная колода — бесконечная, а не мультиколода.** Каждая карта тянется
случайно из 54 типов, повторы ничем не ограничены. Причина: проще и гарантированно
хватает на любую раздачу, сколько бы игроков ни село.

**Одинаковые карты во взятке — берёт положивший раньше.** Награждает
решительность и совпадает с тем, как функция ведёт себя сегодня.

**Крюк при одновременных заказах отключается.** Цеплять правило не к чему.

**Заказ вслепую и одновременные заказы — разные механизмы.** Первый про свою
руку, второй про чужие ставки. Настраиваются независимо, сочетаются.

**Бонус за заказ вслепую начисляется только при точном заказе** (+5 сверх
обычных очков), минусы при промахе — в полном объёме, без скидок.

**Конфиг редакции снапшотится в состояние матча при старте** (уже работает,
`state["rules"]`). Правка редакции не меняет правила идущих матчей. Это
развязка, без которой сезоны невозможны — закрепить тестом.

## Открытые вопросы

- **Авто-ход за игрока, который заказывает вслепую.** Таймер сейчас делает
  минимальный допустимый заказ. Открывать ли руку перед этим? Предложение:
  открывать (авто-ход не должен молча тратить возможность получить бонус).
- **Где живёт эталонная редакция сезона** — обычная запись в `rules_editions`
  с пометкой в `meta`, или отдельная таблица сезонов. Решается на этапе 3.
